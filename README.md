# 🎮 Hangman Game

A fun, interactive word-guessing game developed using Python. The player tries to guess a hidden word by suggesting letters one at a time before running out of attempts.

## 📌 About the Project

Hangman is a classic word-guessing game built using Python. In this game, the computer selects a secret word, and the player must guess it by entering one letter at a time.

For every incorrect guess, the player loses an attempt. The objective is to guess the complete word before all attempts are used.

This project was developed as part of my Python programming and internship learning journey to improve my understanding of programming logic and problem-solving.

## ✨ Features

* 🎯 Random word selection.
* 🔤 Letter-by-letter word guessing.
* ❤️ Limited attempts for incorrect guesses.
* 📊 Displays correctly guessed letters.
* ❌ Tracks incorrect guesses.
* 🏆 Win and lose conditions.
* 🔄 Interactive command-line gameplay.

## 🛠️ Technologies Used

* **Python 3**
* Random Module
* Loops and Conditional Statements
* Lists and Strings
* User Input Handling

## 🚀 Getting Started

### Prerequisites

* Python 3 installed on your computer.
* A code editor such as Visual Studio Code.

### Installation

**1. Clone the repository:**

```bash
git clone https://github.com/marooff18/hangman-game.git
```

**2. Open the project folder:**

```bash
cd hangman-game
```

**3. Run the game:**

```bash
python hangman.py
```

## 🎮 How to Play

1. Start the Python program.
2. The computer selects a secret word.
3. Enter one letter at a time to guess the word.
4. Correct guesses reveal the matching letters.
5. Incorrect guesses reduce your remaining attempts.
6. Guess the complete word before running out of attempts to win!
